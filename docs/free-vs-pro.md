# EITO — Free vs Pro Plan Comparison

## Usage Limits

| Feature | Free | Pro |
|---------|------|-----|
| Recipe Extractions | 5 per week | Unlimited |
| Fridge Scans | 3 per week | Unlimited |
| AI Chef Chats | 20 per week | Unlimited |
| Saved Recipes | Limited | Unlimited |

Usage resets every 7 days for free users.

## In-App Behavior

| Behavior | Free | Pro |
|----------|------|-----|
| Home screen indicator | Shows remaining/total (e.g. 3/5) | Shows infinity icon |
| Profile Usage section | Visible with progress bars | Hidden |
| Profile Subscription row | "Free Plan" | "Eito Pro" with accent |
| Subscription screen | Usage stats + feature preview + upgrade CTA | Membership card + unlocked features grid + manage button |
| Usage gate (limit reached) | Blocks action, shows UsageLimitSheet | Never triggers |
| Recipe extraction billing | Charged on save (not extract) | No limit |
| Usage details screen | Cards with progress bars + reset countdown + upgrade CTA | Cards showing "Unlimited" |
