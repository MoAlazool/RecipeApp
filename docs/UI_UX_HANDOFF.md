# ملخص شامل للتطبيق (UI/UX Handoff)

> الهدف: هذا المستند يجمع كل الصفحات والأفكار والتدفقات الموجودة حاليًا في التطبيق كما هي في الكود. الغرض منه تسليم كامل لمصمم UI/UX لإعادة التصميم بدون فقد أي جزء وظيفي.

## 1) نظرة عامة على المنتج
- **الفكرة الأساسية:** تحويل فيديوهات الطبخ إلى وصفات قابلة للطبخ باستخدام الذكاء الاصطناعي، مع إدارة وصفات محفوظة، قائمة مشتريات، ووضع طبخ خطوة بخطوة.
- **القيمة للمستخدم:**
  - يلصق رابط فيديو (YouTube/TikTok/Instagram) → يحصل على وصفة مفصلة.
  - يصوّر الثلاجة → التطبيق يتعرف على المكونات ويقترح وصفات.
  - دردشة مع AI Chef لاقتراح وصفات.
  - وضع طبخ مع مؤقتات، قراءة صوتية، وتتبع الخطوات.
  - إدارة قائمة مشتريات مرتبطة بالمكونات.

## 2) خريطة التنقل (Information Architecture)
### الجذر (Root)
- `/` → Redirect بناءً على حالة تسجيل الدخول:
  - غير مسجل → `/welcome`
  - مسجل → `/(tabs)`

### ما قبل التسجيل (Pre-auth)
- `/welcome` → شاشة الترحيب الرئيسية.
- `/onboarding` → 3 شرائح تعرّف ميزات التطبيق.
- `/auth` → تسجيل دخول/تسجيل جديد + نسيت كلمة المرور.
- `/auth/callback` → معالجة تسجيل الدخول عبر مزود خارجي (OAuth callback).

### تبويبات التطبيق (Tabs)
- `/(tabs)/index` → الصفحة الرئيسية (الوصفات).
- `/(tabs)/ai-chef` → شات AI Chef.
- `/(tabs)/shopping` → قائمة المشتريات.
- `/(tabs)/profile` → الملف الشخصي والإعدادات.

### شاشات خارج التبويبات (Stack Screens)
- `/add-recipe` → إضافة وصفة من رابط/إدخال يدوي.
- `/(tabs)/add` → شاشة اختيار طريقة الإضافة (يوتيوب/تيك توك/إنستغرام/يدوي).
- `/recipe/[id]` → تفاصيل وصفة.
- `/cooking/[id]` → وضع الطبخ.
- `/recipe-results` → نتائج وصفات من الثلاجة (Flashcards + فلاتر).
- `/suggested-recipe-detail` → تفاصيل وصفة مقترحة (مع حفظها للوصفات).
- `/fridge-scan` → تصوير الثلاجة بالكاميرا.
- `/fridge-review` → مراجعة وتحليل صورة الثلاجة (AI scanning + تعديل العناصر).
- `/scan-detail` → تفاصيل نتائج المسح.
- `/recent-scans` → قائمة أحدث عمليات المسح.
- `/paywall` → شاشة الاشتراك المدفوع.

> يوجد ملف احتياطي قديم: `/recipe-results-slider-backup` (نسخة سابقة من نتائج الوصفات).

## 3) الكيانات الأساسية (Data Entities)
- **Recipe**: عنوان، وصف، نوع المطبخ، صعوبة، أوقات التحضير/الطبخ، حصص، مكونات، خطوات، سعرات ومغذيات، مفضلة، مرات الطبخ، آخر طبخ، رابط المصدر، صورة مصغرة.
- **Ingredient**: اسم، كمية، وحدة، فئة (produce/meat/etc)، ملاحظات، اختياري.
- **RecipeStep**: رقم الخطوة، نص التعليمات، مدة الخطوة، حرارة.
- **ShoppingItem**: عنصر قائمة مشتريات (اسم/كمية/وحدة/فئة/صفة عاجلة/مربوط بوصفة).
- **FridgeScan**: نتيجة مسح ثلاجة (صورة + قائمة مكونات مكتشفة + توقيت).

## 4) تدفقات المستخدم الرئيسية (User Flows)
### A) تحويل فيديو إلى وصفة
1) من الصفحة الرئيسية → زر “Paste Link” أو من شاشة الإضافة.
2) ينتقل إلى `/add-recipe`.
3) النظام يستخرج الوصفة تلقائيًا من الرابط.
4) حالة استخراج (Progress) → قد يطلب إدخال يدوي إذا فشل.
5) عرض معاينة وصفة (`RecipePreview`).
6) حفظ الوصفة → تظهر في قائمة الوصفات.

### B) مسح الثلاجة → اقتراح وصفات
1) من الصفحة الرئيسية → “Scan Fridge”.
2) شاشة الكاميرا `/fridge-scan` → تصوير أو اختيار صورة.
3) شاشة المراجعة `/fridge-review`:
   - تحليل AI + إظهار العناصر.
   - تعديل/حذف عناصر.
   - حفظ المسح.
4) عرض النتائج:
   - `/scan-detail` لعرض العناصر.
   - `/recipe-results` لعرض وصفات مقترحة بنظام Flashcards.

### C) الشات مع AI Chef
1) من تبويب AI Chef.
2) يكتب المستخدم طلبه (مثال: “عايز وصفة سريعة”).
3) AI يرد بنص + كروت وصفات.
4) الضغط على كرت وصفة يفتح `/suggested-recipe-detail`.

### D) إدارة قائمة المشتريات
- إضافة عناصر يدويًا أو من وصفة.
- تنظيم بالعناوين (حسب الفئة أو حسب الوصفة).
- swipe actions: عاجل/حذف.
- العناصر المفحوصة تنتقل لقسم “Checked Items”.

### E) وضع الطبخ (Cooking Mode)
- خطوات كاملة مع تنقل السابق/التالي.
- مؤقت خطوة واحدة أو متعددة.
- قراءة صوتية للخطوات.
- تنبيه عند انتهاء المؤقت.
- تحديث عدد مرات الطبخ.

## 5) تفاصيل الشاشات (Screen-by-Screen)

### `/welcome`
- Hero صورة خلفية + شعار + وصف مختصر.
- أزرار: Get Started → Onboarding، Sign In → Auth.

### `/onboarding`
- سلايدات تعريفية (3) + نقاط تقدم.
- زر Next/Get Started.
- زر Skip.

### `/auth`
- تبادل بين Sign In / Sign Up.
- حقول: البريد + كلمة المرور (+ الاسم في Sign Up).
- نسيت كلمة المرور (Forgot Password view).
- تسجيل دخول Google (في store).

### `/(tabs)/index` (الرئيسية)
- شريط علوي مع الترحيب.
- بحث عن وصفة.
- Hero card لنسخ رابط فيديو.
- زر Paste Link (يلصق من Clipboard ويبدأ استخراج مباشر).
- Quick actions: Scan Fridge / Browse Saved.
- قائمة الوصفات (حديثة + كل الوصفات).
- Empty state في حال لا توجد وصفات.

### `/(tabs)/ai-chef`
- واجهة شات.
- رسائل المستخدم والـ AI.
- Suggestions Chips جاهزة.
- AI recipes cards داخل المحادثة.
- Input أسفل الشاشة مع رفع على الكيبورد.

### `/(tabs)/shopping`
- Header + عداد إجمالي العناصر.
- Quick add input.
- Tabs للعرض: By Aisle / By Recipe.
- قائمة عناصر مع checkbox دائري.
- Swipe actions: urgent / delete.
- Checked Items section (قابل للفتح/الإغلاق).
- زر حذف الكل checked.
- إمكانية مشاركة القائمة.
- إضافة عنصر عبر Modal.

### `/(tabs)/profile`
- إذا غير مسجل → دعوة لتسجيل الدخول.
- إذا مسجل:
  - معلومات الحساب.
  - أقسام إعدادات (Account/Preferences/Support).
  - زر Sign Out.

### `/(tabs)/add`
- شاشة اختيار طريقة الإضافة:
  - YouTube / TikTok / Instagram / Manual.

### `/add-recipe`
- إدخال رابط فيديو.
- كشف المنصة تلقائيًا.
- استخراج وصفة (Progress + حالات متعددة).
- عرض RecipePreview للمراجعة.
- إدخال يدوي إذا فشل الاستخراج.

### `/recipe/[id]`
- Hero image + عنوان + وصف.
- أزرار علوية: مشاركة / حذف / مفضلة.
- عرض وقت + سعرات + حصص.
- تبويبات Ingredients / Steps.
- تعديل الحصص.
- إضافة كل المكونات لقائمة المشتريات.
- زر Start Cooking.

### `/cooking/[id]`
- وضع طبخ خطوة بخطوة.
- مؤقتات متعددة.
- قراءة صوتية.
- زر إنهاء الطبخ بتقييم سريع.

### `/fridge-scan`
- شاشة كاميرا مع زر تصوير.
- زر اختيار من المعرض.
- زر Recent Activity.
- تأثير مسح Scan animation.

### `/fridge-review`
- عرض صورة الثلاجة.
- تحليل AI + مؤشرات على الصورة.
- قائمة العناصر المكتشفة (مع نسبة ثقة + كمية).
- تعديل/حذف عنصر.
- حفظ المسح.

### `/scan-detail`
- عرض العناصر المكتشفة في قائمة.
- زر: Find Recipes → recipe-results.
- زر: Chat with AI Chef.

### `/recent-scans`
- قائمة بالعمليات السابقة.
- كل عنصر يفتح scan-detail.

### `/recipe-results`
- واجهة Flashcards للوصفات.
- Meal Type Tabs (Breakfast/Lunch/Dinner).
- Pantry chips (المكونات المحددة).
- أزرار أسفل: Cook Now + Filter.
- Modal للفلاتر/الترتيب.

### `/suggested-recipe-detail`
- تفاصيل وصفة مقترحة من AI.
- تحويل الوصفة المقترحة لوصفة كاملة.
- حفظ للوصفات.
- Cook Now (يحفظ ثم يطبخ).

### `/paywall`
- عرض مميزات الاشتراك.
- خطط الاشتراك.
- Restore purchases.

## 6) مكونات UI المهمة (Reusable Components)
- `RecipeCard` → بطاقة وصفة في القوائم.
- `RecipeFlashcard` → بطاقة كبيرة مع سوايب للنتائج.
- `RecipePreview` → معاينة قبل الحفظ.
- `IngredientList` / `StepList` → عرض مكونات وخطوات.
- `ServingAdjuster` → تعديل عدد الحصص.
- `CookingTimer` / `CookingProgress` → مؤقتات ووضع الطبخ.
- `AddItemModal` → إضافة عنصر لقائمة المشتريات.
- `FloatingTabBar` → شريط تبويبات عائم.
- `EmptyState` / `LoadingOverlay` → حالات فارغة وتحميل.

---

## 7) خدمات خلفية وأفكار داعمة (Back-end + AI)
- **AI Service**:
  - استخراج وصفة من الفيديو/النص.
  - توليد وصفات من مكونات الثلاجة.
  - توسيع الوصفات المقترحة لوصفة كاملة.
- **Social Service**: دعم يوتيوب/تيك توك/إنستغرام واستخراج البيانات.
- **Firebase**: تخزين الوصفات، قائمة المشتريات، نتائج المسح.
- **Pantry Service**: إدارة مخزون الثلاجة.
- **Notifications + Live Activity**: للمؤقتات في وضع الطبخ.
- **RevenueCat**: للاشتراكات.

---

## 8) حالات النظام (States)
- حالات تحميل واستخراج في add-recipe.
- حالات فارغة (No recipes / No scans / No items).
- حالات خطأ في الذكاء الاصطناعي أو تحميل البيانات.
- حالات التقدم في cooking mode.
